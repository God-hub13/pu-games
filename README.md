# pu-games

Игры с открытым кодом для галереи **Pleasure Union** (мини-приложение в Telegram).
Каждая папка — отдельная игра. В галерею она добавляется ссылкой на папку:

```
https://github.com/God-hub13/pu-games/tree/main/<папка>
```

Все игры сделаны **людьми**, их авторы указаны ниже. Мы их не писали. Мы
только адаптировали их под Telegram и телефон, и каждое изменение перечислено
здесь. Это требование лицензий (GPL «изменённые файлы должны нести заметное
уведомление», MPL — то же для изменённых файлов) и просто честно.

  - в папку попадают только используемые картинки (значок, App Store) — без
    шрифтов из репозитория автора (`webpack.config.js`);
  - wasm собран без wasm-opt (`crate/Cargo.toml`) — файл чуть больше, игра та
    же;
  - добавлены описание и метки для галереи, `pu-tg.js`, обложка и иконка
    (снимок сцены, нарисованной в самой игре).

## Общее для всех игр

- `pu-tg.js` — склейка с Telegram: «Назад» возвращает в галерею, свайп вниз не
  закрывает приложение, шапка в цвет игры. Эталон — `tools/pu-tg.js`, в папки
  игр копируется командой ниже.
- `cover.png` и `icon.png` — обложка и иконка для карточки в галерее. Для 2048,
  Clumsy Bird и A Dark Room они собраны из элементов самих игр
  (`tools/art/*.html`), для Hextris — снимок игры и иконка из её репозитория,
  для Sandspiel — снимок сцены из самой игры.

## Перед каждым пушем

```
python3 tools/check.py --fix
```

Проверяет каждую игру: лицензия на месте, игра записана в этот README, есть
описание и метки для галереи, подключены Telegram и `pu-tg.js`, есть обложка и
иконка, нет чужой рекламы и счётчиков. Код выхода 1 — что-то не так.
