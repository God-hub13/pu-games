# Fish Folk: Jumpy — для галереи Pleasure Union

Рыбья перестрелка в духе Duck Game: до четырёх рыб на одной карте, оружие
валяется на уровне, против ботов. Игра сделана **людьми** — командой Fish
Folk (Spicy Lobster); мы её не писали, только подготовили для Telegram и
телефона. Все наши изменения перечислены ниже.

Отдельная ветка (`jumpy`): игра весит около 46 МБ. Ссылка для галереи:

```
https://github.com/God-hub13/pu-games/tree/jumpy
```

## Что мы изменили

Только `index.html` и три новых файла рядом; сама игра та же.

- `index.html`:
  - язык, название, описание и метки для галереи; «Загрузка…» вместо
    «Loading game...»;
  - **ширина страницы 980px** (`<meta name="viewport">`). Без этой метки
    так и было — мобильный браузер по умолчанию считает страницу шириной
    980px, и меню игры рассчитано на это. Метка закрепляет ширину в любом
    webview и выключает масштаб пальцами (он сбивал бы управление);
  - стили экранного геймпада и просьба повернуть телефон (`#pu-rotate`).
- `pu-pad.js` (новый) — **управление пальцем**: экранный геймпад
  (крестовина, «Прыжок», «Огонь», «Взять», «Подкат», «Пауза», «Старт»)
  жмёт клавиши первого игрока; касание меню превращается в клик мышью —
  пальцем игра меню не понимала. Подробности — в начале файла. Только на
  сенсорном экране.
- `pu-landscape.js` (новый) — на телефоне просит Telegram открыть игру на
  весь экран и закрепляет поворот боком; при выходе всё возвращает.
- `pu-tg.js` — общая склейка с Telegram для всех игр галереи (эталон —
  `tools/pu-tg.js` в ветке `main`).
- `cover.png` — кадр из игры с названием, набранным шрифтом игры (Ark
  Pixel); `icon.png` — рыба Fishy из экрана выбора игрока.
- Надписи в игре остались английскими: шрифт игры только латинский.

## Как играть

1. Положи телефон боком.
2. Тапни «Local Game».
3. «Прыжок» — войти в игру, выбрать рыбу и шапку (стрелки — листать).
4. Тапни «Add AI Player» в соседних окошках — это боты-соперники.
5. «Старт» — дальше, тапни карту.
